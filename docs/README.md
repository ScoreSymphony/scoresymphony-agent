# Documentation

This directory records the current application architecture and integration order. It does not claim that external workers, reviewers, orchestration systems, Git worktrees or production deployment are already active.

Start with:

- `architecture.md` — implemented bootstrap boundaries and safety baseline.
- `adapter-roadmap.md` — order for adding real workspaces, deterministic tools, FCC, Codex, dashboard, Hermes and later local workers.

Documentation must distinguish implemented behavior from deferred integration work.
